## Contributing to [Memerz](https://github.com/treatwashere/Memerz)

To contribute to Memerz, follow these steps:

1. [Fork](https://github.com/treatwashere/Memerz/fork) the repository to your GitHub account.
2. Clone the repository to your device (or use something like Codespaces).
3. Create a new branch in the repository.
4. Make your changes.
5. Commit your changes and push the branch.
6. [Create a Pull Request](https://github.com/treatwashere/Memerz/compare) from the branch in your fork to Memerz' `main` branch.

##

You're done!

Now just wait for the moderators to accept your request and you'll be a contributor!
